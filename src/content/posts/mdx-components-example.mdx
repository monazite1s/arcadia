## Alert 提示框组件

Alert 组件用于显示重要提示、警告、错误或成功信息,支持 4 种类型。

### Info - 信息提示

<Alert type="info" title="💡 信息提示">
    这是一个**信息提示框**,用于显示一般性的提示信息。支持 **Markdown
    语法**,包括加粗、斜体、`行内代码`等。
</Alert>

### Warning - 警告提示

<Alert type="warning" title="⚠️ 注意事项">
    这是一个**警告提示框**,用于提醒用户注意某些重要事项。

    - 可以包含列表
    - 支持多行内容
    - 自动适配深色/浅色主题

</Alert>

### Error - 错误提示

<Alert type="error" title="❌ 错误信息">
    这是一个**错误提示框**,用于显示错误信息或失败状态。

    ```bash
    # 甚至可以包含代码块
    npm install error-package
    ```

</Alert>

### Success - 成功提示

<Alert type="success" title="✅ 操作成功">
    这是一个**成功提示框**,用于显示操作成功的消息。非常适合用于教程中标记完成的步骤!
</Alert>

## Callout 标注框组件

Callout 组件用于突出显示重要内容或补充说明,可以自定义 emoji 图标。

<Callout emoji="📌">**默认标注**: 使用默认的 📌 图标,适合一般性的重点标注。</Callout>

<Callout emoji="💡">**提示标注**: 使用 💡 图标,适合提供额外的提示或技巧。</Callout>

<Callout emoji="🚀">**最佳实践**: 使用 🚀 图标,适合分享最佳实践或性能优化建议。</Callout>

<Callout emoji="📚">
    **参考资料**: 使用 📚 图标,适合引用文档或外部资源。可以包含链接:[MDX
    官方文档](https://mdxjs.com/)
</Callout>

<Callout emoji="⚡">
    **快速提示**: Callout 组件非常适合用于: - 重点标注关键信息 - 补充说明和注意事项 -
    提供额外的上下文 - 分享技巧和最佳实践
</Callout>

## YouTube 视频组件

YouTube 组件用于嵌入 YouTube 视频,自动响应式布局。

<Alert type="info" title="使用说明">
    只需提供 YouTube 视频 URL 中 `v=` 后面的视频 ID 即可。 例如:
    `https://www.youtube.com/watch?v=dQw4w9WgXcQ` 中的 ID 是 `dQw4w9WgXcQ`
</Alert>

<YouTube id="dQw4w9WgXcQ" title="Rick Astley - Never Gonna Give You Up" />

<Callout emoji="📺">YouTube 组件会自动保持 16:9 的宽高比,并在不同屏幕尺寸下响应式调整。</Callout>

## CodeSandbox 代码沙盒

CodeSandbox 组件用于嵌入可交互的代码示例,非常适合技术教程。

<Alert type="info" title="使用说明">
    提供 CodeSandbox 项目的 ID,可以从 CodeSandbox URL 中获取。 例如:
    `https://codesandbox.io/s/react-new` 中的 ID 是 `react-new`
</Alert>

<CodeSandbox id="react-new" title="React 基础示例" />

<Callout emoji="💻">
    CodeSandbox 组件会嵌入一个完整的在线 IDE,读者可以直接在文章中编辑和运行代码。
</Callout>

## 主题适配

所有组件都完美支持深色/浅色主题切换:

<Callout emoji="🌓">
    **自动主题适配**: 所有 MDX 组件都使用 CSS 变量,会自动适配当前主题。试试切换主题看看效果!
</Callout>

<Alert type="info" title="技术实现">
    组件使用 `--mdx-*` CSS 变量,在 `globals.css` 中统一管理颜色,确保主题切换时的一致性。
</Alert>

## 最佳实践

<Callout emoji="📌">
    **组件使用建议**: 1. **Alert**: 用于重要信息、警告、错误提示 2. **Callout**:
    用于补充说明、技巧、最佳实践 3. **Image**: 合理选择尺寸,添加有意义的 caption 4.
    **YouTube/CodeSandbox**: 用于增强教程的互动性 5. **组合使用**: 创建结构化、易读的内容
</Callout>

<Alert type="warning" title="注意事项">
    - 不要过度使用组件,保持内容的可读性 - 确保 alt 文本和 caption 有意义 -
    外部资源(YouTube/CodeSandbox)需要网络连接
</Alert>

## 代码示例

当然,标准的 Markdown 代码块也完全支持:

```typescript
// TypeScript 代码示例
interface User {
    id: number;
    name: string;
    email: string;
}

const user: User = {
    id: 1,
    name: "Alice",
    email: "alice@example.com",
};

console.log(`Hello, ${user.name}!`);
```

```jsx
// React 组件示例
function Welcome({ name }) {
    return (
        <div className="welcome">
            <h1>Hello, {name}!</h1>
            <p>Welcome to our blog!</p>
        </div>
    );
}
```
