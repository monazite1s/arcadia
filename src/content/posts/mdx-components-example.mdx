## Callout 组件示例

<Callout emoji="💡">**重点提示**：Callout 组件适合用来突出显示重要内容或补充说明。</Callout>

<Callout emoji="📌">你可以自定义 emoji 来表达不同的含义。</Callout>

<Callout emoji="🚀">这个组件非常适合用于： - 重点标注 - 补充说明 - 提示信息 - 最佳实践</Callout>

## 代码示例

普通的代码块：

```typescript
// 这是普通的代码块
interface User {
    id: number;
    name: string;
    email: string;
}

const user: User = {
    id: 1,
    name: "Alice",
    email: "alice@example.com",
};
```

## 组合使用

你可以将多个组件组合使用：

<Alert type="info" title="组合示例">
    在 Alert 组件中，你可以使用 **Markdown 语法**： - 列表项 1 - 列表项 2 - 列表项 3 还可以使用
    `行内代码` 和 [链接](https://example.com)。
</Alert>

<Callout emoji="💡">
    **最佳实践**： 1. 使用 Alert 组件来显示重要提示 2. 使用 Callout 组件来突出重点内容 3.
    保持组件使用的一致性
</Callout>

MDX 让你可以在 Markdown 中使用 React 组件，使文章更加丰富和交互式！
